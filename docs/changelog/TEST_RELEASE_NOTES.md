# What's New

*Changes since v2.27.0 — test release*

**Recitation Collections**
- Add your own chants to practice or bookmarks with a single tap
- Reorder the chants inside a collection, and see the correct count in "N chants"
- Track how many days you've completed a collection
- Faster-loading, better-cropped cover images
- Various small fixes to collection creation and cover uploads

**Group Events**
- Fixed several issues around joining and viewing puja/livestream events
- Live YouTube streams now play embedded in the event screen
- If a livestream can't load, the event screen now stays open instead of closing itself
- Updated event and group cards

**Group Chat**
- Report a message you find inappropriate
- Chat list loads more reliably and shows unread messages more accurately
- Fixed a few cases where messages or read status could get out of sync

**Practice & Routine**
- Give your routine time blocks a custom title
- Fixed mala bead labels getting clipped with larger text sizes
- Fixed the mala icon missing on group accumulations without a cover image

**Other**
- Faster app translations (switched to a lighter-weight delivery system)
- Fixed a splash screen glitch and added rotating taglines on launch
- Small fixes to bookmarks and group post notifications
